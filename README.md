# 망켓몬 세션 노트

캠페인마다 **지도 · 관계도 · 항목 · PC 시트 · 시나리오 · 일정**을 적어 두는 GM 노트. 오레마스(웹툴) · 제작기와 같은 Supabase 프로젝트를 쓰고, 정적 페이지(GitHub Pages)로 돌아간다.

- 여러 캠페인(무진, Neo, …)을 한 곳에서. 캠페인마다 GM 비밀구 하나, PL 좌석 비밀구 여럿.
- 문서마다 공개 범위: **모두 / GM만 / PL 한 사람에게만**. 링크만 있으면 「모두」인 것만 보인다.
- PL 은 자기 PC 시트(RP 칸)와 자기 일정(○△×)만 고칠 수 있다.
- PC 시트는 제작기 트레이너를 읽어 와(읽기 전용) RP 칸만 덧붙인다.
- 일정: 세션 날짜 · 달력 · 후보 날짜 투표 · 평소 되는 요일 · Google 캘린더 추가 링크 · .ics 내려받기.
- 오레마스에서 「📓 세션 노트에서 가져오기」로 지도(장소 · 루트)와 관계도(인물 · 조직 · 관계)를 방으로 가져갈 수 있다.
- 휴대폰에서도 쓸 수 있게 짰다 (탭 가로 스크롤 · 지도 꼬집어 확대 · 표는 가로 스크롤).
- 전체 검색(위 띠 🔍 · 단축키 `/`): 항목 · 장소 · 루트 단계 · 시트 · 기록 · 세션 · 설계 메모 · 던전을 한꺼번에. PL 은 자기가 볼 수 있는 것만.
- GM 「👁 PL 눈」: 모든 탭을 구경(또는 고른 좌석)의 눈으로 본다. 켜 둔 동안은 저장하지 않는다.
- 변경 이력(항목 · 장소 · 루트 · 시트의 「🕘 이력」 → 옛 판으로 되돌리기) · 휴지통(설정 탭 「🗑 최근 지운 것」, 30일). `supabase/patch_2026-11-03_노트.sql` 이 필요하다.
- 세션(일정 탭)마다 GM 만 보는 준비 체크리스트 · 쓸 것(루트 · 장면 · 인물 · 지도 링크) · 끝난 뒤 회고.
- 시나리오 단계의 「▶ 웹툴로」: 낭독문을 나레이션으로, 장소 그림을 배경으로, 등장 인물 스탠딩을 무대로 이어 둔 웹툴 방에 한 번에 (씬 프리셋 `rp.scenes.<id>` 로도 남긴다).
- 계정 PL 의 자리 앉기는 「모두」 공개된 PC 시트만. 캠페인 설정 「PL 자리 앉기」를 「GM 승인 뒤」로 두면 요청이 설정 탭에 떠서 승인 · 거절한다.
- 시나리오 「조직」(11-13, GM만): NPC 를 세 명씩 한 그룹(조직)으로 묶어 도안의 큰 사건마다 놓는 스케치 판. 인물 칸에 그림 파일 · 서랍(자료의 인물 항목 · NPC 시트)을 끌어 놓고, 누르면 옆 창 · 이름 두 번 누르면 그 자리에서 고치기 · 우클릭(길게 누르기) 메뉴. 칸은 「👁 공개 소개」(PL 에게 보일 글)와 「🔒 GM 설정」(절대 안 나감)으로 나뉜다. 「👁 공개로」 = 자료 탭 인물 · 조직 항목(카드)을 만들어 이름 · 그림 · 소속 · 공개 소개만 넣고 공개. 단서는 도안 사건 단서(grp · who)라 도안 · 웹툴과 그대로 이어진다. 「▶ 웹툴 무대로」 · 「11-13 배치 안으로 5개 넣기」 · 「글로 복사」. 문서 kind `grp` (`js/cast_ui.js` · `css/cast.css`).
- 시나리오 「▶ 진행」 뷰(11-03): 지금 단계 하나를 크게 — 낭독문(큰 글씨) · 등장 인물 카드(단계 · 장소의 인물 · PC · NPC) · 장소 미니맵 · 「▶ 웹툴로」 · 「끝 → 다음」 · 이전/다음 미리보기. 키 `N` 다음 · `P` 이전(보는 자리만). PL 도 공개된 루트는 본다(GM 메모는 GM 만).
- 발표 모드(11-03, 화면 공유용): 지도 · 관계도(보드) · 흐름도 · 진행 뷰의 「⛶」 또는 `Shift+F` — 위 띠 · 툴바 · 레일 · 패널을 숨기고 판만 100dvh, 🔒 GM 전용(비공개 핀 · 루트 · 카드 · 실 · GM 메모)은 안 보인다. `Esc` 로 돌아온다. 탭을 바꾸면 풀린다.
- 단축키(11-03): `1`~`7` 탭 · `N` 새 항목(항목 탭) · `F` 맞춤(지도 · 흐름도 · 보드) · `Shift+F` 발표 모드 · `/` 검색 · `Esc`. 입력칸 · 창이 열려 있을 땐 무시.
- 지운 뒤 토스트의 「실행 취소」(5초): 항목 · 장소(이음선 포함) · 루트 · 관계 · 세션 · 메모 · 기록 · 일정 비우기를 바로 되살린다(지우기 직전 사본을 put force — 휴지통과 같은 길).
- 휴대폰(640px 이하): 위 띠의 PL 눈 · 검색 · 알림 · 웹툴 · 로그인 · 나가기 · 테마는 「⋯」 메뉴로. 지도 · 관계도 · 항목 툴바의 거르기 칩은 「필터 ▾」 한 단추 뒤로(걸러진 수가 배지로), 안내문은 숨김.
- 새 캠페인(PC · 항목 · 지도 · 루트가 빈 것)은 탭 위에 「시작 안내」 체크리스트(각 단추가 그 탭으로). 하나라도 생기면 한 줄로 접히고, ✕ 로 치우면 설정 탭 「화면」에서 다시 켠다. 「일정 비우기 · 설계 메모 비우기」도 설정 탭 「위험」으로 옮겼다.
- 지도 틀 높이는 그림 비율대로(화면보다 길면 화면 높이까지), 루트 이름은 첫 단계 핀 옆 배지. 관계도 보드는 카드 최소 118px · 관계 이름 라벨 기본 표시 · 종류별 실(보통 빨강 · 우호 초록 · 적대 금색 · 애정 분홍 점선 · 비밀 검정 점선). 항목 상세 본문 17px · 줄간 1.8. 흐름도는 열 때 자동 「맞춤」.

## 처음 켜기

1. Supabase SQL Editor 에서 `supabase/schema.sql` 을 한 번 돌린다 (nt_camp · nt_auth · nt_docs 표, nt_* 함수, 정책). 다시 돌려도 된다. 그 뒤 `supabase/patch_2026-10-29_계정.sql` → `patch_2026-10-29_PL기본.sql` → `patch_2026-11-03_노트.sql` 차례로 (여러 번 돌려도 된다).
   - 11-03 패치: 캠페인 설정 칸 단위 합치기(`nt_camp_patch`) · 자리 앉기 공개 시트 · GM 승인(`nt_claim2` · `nt_claim_decide`) · 변경 이력 · 휴지통(`nt_docs_history` · `nt_history` · `nt_deleted`) · 그림 저장소 정책(anon 목록 읽기 · 덮어쓰기 제거 — **웹툴 · 제작기와 같이 쓰는 버킷이라 셋 다 영향**, 공개 주소로 보는 것은 그대로). 패치 전이면 클라이언트는 예전 방식으로 돌아간다(이력 · 휴지통은 「함수가 없다」고 알린다).
2. 저장소 설정 → Pages → Branch `main` / root. 주소: `https://mangryoung.github.io/mangketmon-notes/`
3. 첫 화면에서 캠페인 이름과 GM 비밀구를 적고 「만들기」. 비밀구는 그 브라우저에 저장된다.
4. 다른 기기에서는 설정 탭의 GM 링크(`?gm=…`)를 한 번 연다. PL 에게는 설정 탭 → PL 좌석 → 「초대 링크」(`?pl=…`).

## 같이 저장할 때 (11-03)

- 문서 한 장 저장(`put`)과 여러 장 저장(`putMany` — 순서 바꾸기 · 한꺼번에 공개 · 관계도 배치)은 저장 직전에 DB 의 최신 판을 읽어 내가 고친 칸만 바꾼다. 가져오기(JSON 올리기 · 되살리기)만 통째로 쓴다.
- 캠페인 설정(`nt_camp.data`)은 `NT.campPatch({칸:값})` 로 칸 단위로 합친다(null = 그 칸 지움). 받아 둔 옛 설정으로 통째 덮지 않는다. 웹툴 `notes_link.js` 도 같은 함수(`nt_camp_patch`)를 쓰도록 diff 를 남겼다.

## Supabase 사용량 (무료 티어 기준)

- DB: 문서는 JSON 한 줄씩, 그림은 저장소에 따로. 무진 전체가 208줄 · 1MB 가 안 된다. 캠페인 10개여도 DB 500MB 에는 턱없이 적다.
- 읽기: 열 때 한 번 전체(`nt_all`), 그 뒤로는 `updated_at` 이후 것만. 공개 문서는 realtime(postgres_changes), 비공개는 broadcast 신호만 → 폴링 없음. 동시 접속 5~6명이면 realtime 메시지는 하루 수백 건 수준(한도 200만/월).
- 저장소 · 전송량: 지도 그림이 가장 크다(무진 지도 3200px JPEG 약 1.5MB). 지도를 열 때마다 내려받지만 브라우저가 캐시한다. 사진은 1600px · 얼굴 512px 로 줄여서 올린다. 한 달 전송 5GB 한도에서, 세션 13회 × 6명이 매번 지도를 새로 받아도 120MB 안쪽.
- 가장 큰 변수는 사진 수. 캠페인 하나에 사진 100장이면 저장소 30~50MB.
